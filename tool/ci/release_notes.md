AllBioHub for Android, version {{VERSION}}.

## Which file?

- **allbiohub.apk** works on almost every Android phone. Pick this one if you're not sure.
- **allbiohub-arm64.apk** is a smaller download for most phones made since 2019. If it says "App not installed", use allbiohub.apk instead.

## How to install

1. Tap the file above to download it. Chrome may say **"This type of file can harm your device"**. Every app downloaded outside Google Play gets this message; tap **Download anyway**.
2. When the download finishes, tap **Open**.
3. If your phone says installing unknown apps isn't allowed, tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**. If Google Play Protect asks to scan the app, tap **Scan app**; when it finds no problems, tap **Install**. (This check appears for apps that aren't on Google Play yet.)
5. Tap **Open**. Updates install the same way, over the existing app; your saved stories are kept.

Already have AllBioHub? Installing a newer version updates it in place.

`SHA256SUMS.txt` lists each file's SHA-256 checksum, so you can check the download is the genuine file.
