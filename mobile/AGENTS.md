This is the AllBioHub Expo/React Native app (Expo SDK 58). See README.md.

Rules for this project:
- No WebView, no fake or demo data, never write to the website. All data comes from allbiohub.com's public REST API and the read-only add-on.
- The Android application ID stays `com.allbiohub.app` and release builds must be signed with the existing AllBioHub key (plugins/with-release-signing.js, RELEASE.md).
- FCM topic names in src/stores/preferences.ts must never change.
- Use Expo Router for navigation; routes live in src/app/. Keep non-route code outside src/app/.
- `android/` and `ios/` are generated by `expo prebuild`; never edit them by hand.
- Install packages with `npx expo install` (offline: `EXPO_OFFLINE=1 npx expo install`).
- Run `npm run typecheck`, `npm run lint` and `npm test` before declaring work done.
